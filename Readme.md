# Interview Prep

A personal knowledge base for technical interview preparation. Notes, solved problems, and reference material organized by topic.

## Topics

| Folder | Focus |
|--------|-------|
| [Python](Python/Python.md) | Python fundamentals, language quirks, and coding patterns |
| [SQL](SQL/SQL.md) | Query practice, window functions, and data interview questions |
| [Statistics](Statistics/Stats.md) | Probability, distributions, hypothesis testing, and A/B testing |
| [Machine Learning](Machine_Learning/Machine_Learning.md) | ML concepts, model evaluation, and ML system questions |
| [GenAI](GenAI/) | LLMs, RAG, agents, and generative AI interview topics |
| [System_Design](System_Design/) | Architecture, scalability, and design trade-offs |

Each topic folder has a main `.md` file for notes and can hold additional problems or subtopics as you add them.

## How to use

1. Pick a topic folder and open its main markdown file.
2. Add problems with the format used in [SQL/SQL.md](SQL/SQL.md): problem statement, examples, and solution.
3. Link related topics across folders when a question spans multiple areas.

## Tools

- **[interview-coach-skill](interview-coach-skill/)** — Claude-based interview coach for behavioral prep, mock interviews, resume review, and the full job-search lifecycle. See its [README](interview-coach-skill/README.md) for setup.

## Structure convention

```
Topic/
├── Topic.md          # Main notes and index
└── problems/         # Optional: individual problem write-ups
```

Keep solutions in markdown with fenced code blocks. Include the source (LeetCode, DataLemur, etc.) when applicable.
