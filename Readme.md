# Interview Bank

A personal knowledge base for interview preparation, coding practice, ML/statistics review, and job-search support. The root README is a guide to the folders; detailed question indexes should live inside each topic folder.

## Folder Guide

| Folder | Focus |
|--------|-------|
| [Python](Python/Python.md) | Python coding questions, data structures, language fundamentals, and common interview patterns |
| [SQL](SQL/SQL.md) | SQL query practice, joins, aggregations, window functions, and data interview problems |
| [Statistics](Statistics/Stats.md) | Probability, hypothesis testing, p-values, confidence intervals, correlation, and A/B testing |
| [Machine Learning](Machine_Learning/Machine_Learning.md) | ML fundamentals, model evaluation, regularization, validation, metrics, and practical ML concepts |
| [GenAI](GenAI/) | LLMs, RAG, agents, prompt engineering, embeddings, and generative AI interview topics |
| [System_Design](System_Design/) | Architecture, scalability, databases, APIs, caching, reliability, and design trade-offs |

Each topic folder can maintain its own index of questions and answers. Keep this global README focused on navigation and study workflow.

## How To Use

1. Start with the folder that matches the interview round.
2. Use the topic file as the index for that subject.
3. Add each new question in the same Q/A format used in the folder.
4. Link related topics when a question spans areas, such as ML evaluation and statistics.
5. Keep answers crisp: definition, intuition, example, key differences, and interview takeaway.

## Interview Prep Workflow

- **Coding rounds:** Practice from [Python](Python/Python.md) and add solved problems by topic.
- **Data interviews:** Use [SQL](SQL/SQL.md), [Statistics](Statistics/Stats.md), and ML evaluation notes together.
- **ML interviews:** Review [Machine Learning](Machine_Learning/Machine_Learning.md), then connect concepts back to statistics.
- **System design rounds:** Use [System_Design](System_Design/) for architecture trade-offs and design frameworks.
- **GenAI roles:** Use [GenAI](GenAI/) for LLM, RAG, agents, and applied AI system topics.

## Job-Search Support

Use this repo not only for technical notes, but also for preparing the full interview loop:

- Resume and project story preparation
- Behavioral interview examples using STAR format
- Mock interview prompts and self-review notes
- Company-specific preparation notes
- Role-specific question lists for data, ML, backend, GenAI, or system design roles

## Skills And Tools

- **Interview coaching:** Use the `interview-coach` skill for behavioral prep, mock interviews, resume review, role targeting, and job-search planning.
- **Visual research:** Use `imagesearch` when a concept benefits from a diagram or visual explanation.
- **Design or slides:** Use design and slides skills when preparing portfolio material, presentations, or interview decks.

## Structure Convention

```text
Topic/
+-- Topic.md          # Main notes and topic-level index
+-- problems/         # Optional: individual problem write-ups
```

Keep solutions in markdown with fenced code blocks. Include the source, such as LeetCode, DataLemur, or documentation, when applicable.
